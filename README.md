# Лабораторная работа: интерполяция

Программа реализует методы, требуемые вариантом:

1. многочлен Лагранжа;
2. многочлен Ньютона с разделенными разностями:
   - первая форма (вперед);
   - вторая форма (назад);
3. многочлен Ньютона с конечными разностями:
   - первая формула (вперед);
   - вторая формула (назад).

Главная логика формул соответствует лекции по интерполяции:
- интерполяционный полином проходит через все узлы;
- разделенные разности допускают неравноотстоящие узлы;
- конечные разности используются для равноотстоящих узлов;
- первая формула Ньютона с конечными разностями удобна для левой половины таблицы;
- вторая — для правой половины;
- для экстраполяции слева используется первая, справа — вторая.

## Возможности

### 1. Три способа ввода

- таблица `x, y` с клавиатуры;
- данные из файла;
- автоматическое построение таблицы по функции.

В программе есть функции:
- `sin(x)`;
- `cos(x)`;
- `exp(x)`.

Пользователь задает интервал и количество точек.

### 2. Таблицы разностей

Программа выводит:
- таблицу разделенных разностей всегда;
- таблицу конечных разностей, если сетка равноотстоящая.

### 3. Сравнение методов

В заданной точке программа вычисляет:
- Лагранж;
- Ньютон с разделенными разностями (вперед и назад);
- Ньютон с конечными разностями (вперед и назад), если сетка равномерная.

Если исходные данные получены от известной функции, дополнительно выводятся:
- точное значение;
- абсолютная погрешность каждого метода.

### 4. График

Для режима функции:
- синяя линия — исходная функция;
- красная — интерполяционный многочлен Ньютона;
- черные точки — узлы.

Для табличного/файлового режима:
- красная линия — интерполяционный многочлен;
- черные точки — узлы;
- зеленая пунктирная линия — соединение табличных точек только для наглядности.

## Запуск

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Формат файла

Пример:

```text
# x y
1.05 0.1213
1.15 1.1316
1.25 2.1459
```

Допускается `;`:

```text
1.05;0.1213
1.15;1.1316
```

## Подготовленные тесты

В каталоге `test_data/` есть минимум три набора:

- `test_equal.txt` — равномерная сетка;
- `test_unequal.txt` — неравномерная сетка;
- `test_quadratic.txt` — значения квадратного многочлена;
- `test_invalid_duplicate_x.txt` — некорректный набор с повтором x.

## Анализ ожидаемых результатов

Если использовать одни и те же узлы, формы Лагранжа и Ньютона описывают один и тот же
интерполяционный многочлен степени не выше `n`. Поэтому в точной арифметике результаты
должны совпадать. Небольшое отличие возможно только из-за ошибок округления `float`.

Первая и вторая формы Ньютона с разделенными разностями также задают один и тот же
многочлен, но строят его с разных концов таблицы.

Для равноотстоящей сетки первая и вторая формулы Ньютона с конечными разностями также
дают тот же интерполяционный полином. По лекции вычислительно удобнее выбирать форму,
начинающуюся с ближайшего края таблицы: первую в левой половине и вторую в правой.

Для большого числа узлов глобальный интерполяционный полином может демонстрировать
колебания и рост численной погрешности. Поэтому результаты следует анализировать не
только по совпадению в узлах, но и по поведению между ними.
